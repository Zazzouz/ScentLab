1. Initial landing page planning (Session 1, early)

I prompted Cursor to generate a clean landing page using only HTML, CSS, and minimal JavaScript with a clear structure and design requirements. This mattered because it established the foundation of the project and ensured it met assignment constraints from the start.

2. Iterative UI refinement (Session 1, midway)

I repeatedly adjusted details like the hero text readability, font choices, and especially the fragrance pyramid layout through multiple back-and-forth fixes. This was important because it shows how I refined the UI through iteration instead of accepting the first result.

3. Debugging and correcting feature issues (Session 2, early)

When presets and images didn’t work correctly, I identified the problems and had Cursor fix missing imports and incorrect mappings. This mattered because it demonstrates debugging and improving functionality, not just generating features.

4. Expanding functionality into a full app (Session 2, midway)

I transitioned the project from a static landing page into a full React application with a fragrance builder, note system, and localStorage saving. This was a key moment because it turned the project into a complete interactive application.

5. Improving system logic and realism (Session 2, later)

I pushed to change the accord profile from manual sliders to a system derived from note data and intensities. This mattered because it improved realism and showed critical thinking about how the system should behave, not just how it looks.
